# moonactuary

用 [MoonBit](https://www.moonbitlang.com) 实现的中国人身保险业经验生命表（CL 2010-2013）寿险精算库，以及一个可以把它全部功能跑一遍的命令行工具。

- 六张经验表（CL1–CL6）的生存函数、换算函数、纯保费与准备金
- 趸缴纯保费、年缴均衡纯保费，终身 / 定期 / 两全三种形态
- 准备金三条独立路径：前瞻法、后顾法、Fackler 递推，互为交叉校核
- 零第三方依赖（仅用 MoonBit 标准库），可在 `wasm`、`wasm-gc`、`js`、`native` 四个后端构建
- 内置 SVG 绘图，对数刻度，用于读死亡率与生存曲线

## 项目目标

中国人身保险业经验生命表（2010-2013）是中国寿险产品定价与法定准备金评估的基准表，但公开可复用的实现并不多，尤其缺少能自我校核的实现。这个项目的目标是：

1. **把六张表做成可复用的库**，生存函数严格复现行内公布的 `Lx`、`Tx`、`ex`；
2. **让结论可以自证**：第一原则恒等式 `1 = A_x + d·ä_x` 在 6 张表 × 3 利率 × 7 年龄上残差为 0，准备金三条路径互相印证，第 n 年末准备金恰等于满期给付额；
3. **一条命令复现全部核心路径**，任何人拿到仓库都能用 `moon run cmd/main demo` 看到同样一组数字；
4. **保持零依赖与多后端**，使它可以嵌入 WASM 前端、评估脚本或服务端程序。

## 安装

### 作为库使用

```bash
moon add hua1104/moonactuary
```

### 从源码构建命令行工具

```bash
# 安装 MoonBit 工具链（Linux / macOS）
curl -fsSL https://cli.moonbitlang.com/install/unix.sh | bash
export PATH="$HOME/.moon/bin:$PATH"

git clone https://github.com/hua1104/moonactuary.git
cd moonactuary

moon build --target native      # 产物：_build/native/debug/build/cmd/main/main.exe
moon build --target all         # 同时产出 wasm / wasm-gc / js / native
```

不构建也可以直接运行，`moon run` 会自行编译：

```bash
moon run cmd/main demo
```

## 快速开始（库）

仓库里有一个可运行的最小样例，打印的就是下面这段代码的结果：

```bash
$ moon run examples/quickstart
CL1 非养老类业务一表（男）
  30 岁生存人数 l30        986359
  30 岁平均余命 e30        47.25
  两全保险趸缴纯保费 A     0.614601
  年缴均衡纯保费 P         0.038895
  第 10 年末准备金 V       0.437487
```

对应代码（`examples/quickstart/main.mbt`）：

```moonbit
// 取一张经验表，构造（表, 利率）估值对
let china = @moonactuary.ChinaTable::of_code("CL1").unwrap()
let table = china.table()
let v = @moonactuary.Valuation::of(
  table=table,
  interest=@moonactuary.Interest::of(0.025),   // 预定利率 2.5%
)

// 生存函数
println(table.lx(30))            // 986359
println(table.expectation(30))   // 47.25，30 岁男性的平均余命

// 两全保险趸缴纯保费与年缴均衡纯保费
println(v.endowment_insurance(30, 20))        // 0.614601
println(v.annual_premium_endowment(30, 20))   // 0.038895

// 准备金：前瞻法
let premium = v.annual_premium_endowment(30, 20)
println(v.reserve_endowment(30, 20, 10, premium))   // 0.437487，第 10 年末
```

## 命令行

```
moonactuary <命令> [选项]
```

| 命令 | 作用 |
| --- | --- |
| `tables` | 列出六张经验表及其零岁平均余命 |
| `table` | 打印生命表函数 `lx / dx / Lx / Tx / ex` |
| `premium` | 计算趸缴纯保费与年缴均衡纯保费 |
| `compare` | 按相同产品假设对比六张经验表的保费结果 |
| `reserve` | 打印逐年准备金表（前瞻 / 后顾 / Fackler 三列） |
| `plot` | 生成 SVG 曲线，输出到标准输出 |
| `demo` | 最小演示：一条命令触发全部核心功能路径 |
| `verify` | 一键验收：跨六张表、三档利率、三类产品交叉校核 |

| 选项 | 含义 | 默认 |
| --- | --- | --- |
| `--table` | 经验表 `CL1`–`CL6` | `CL1` |
| `--age` | 投保年龄 | `30` |
| `--term` | 保险期间（年） | `20` |
| `--rate` | 预定利率百分数，如 `2.5` 表示 2.5% | `2.5` |
| `--product` | 险种 `whole`（终身）/ `term`（定期）/ `endowment`（两全） | `endowment` |
| `--from` `--to` | 生命表年龄区间 | `0` `105` |
| `--kind` | 曲线 `mortality` / `survival` | `mortality` |
| `--format` | `compare` 输出格式 `table` / `csv` | `table` |
| `--help` | 打印用法 | — |

### 一键验收

评审或维护者可以运行 `moon run cmd/main verify`，自动对六张经验表、三档利率与三类产品执行恒等式及准备金交叉校核。成功时输出：

    moonactuary acceptance verification
      生命表：6 张 CL(2010-2013) 经验表
      利率：2.5% / 3.0% / 3.5%
      产品：终身寿险 / 定期寿险 / 两全保险
      恒等式校核：126 项，最大残差 0.000000000000
      准备金校核：1134 项，最大偏差 0.000000000000
    PASS：全部核心精算路径交叉校核通过

CLI 会在计算前检查经验表代码、产品名称、年龄、期间、利率和绘图类型。非法输入会显示明确错误，不会静默替换为默认值或触发数组越界。

## 数据来源与校核

`qx` 取自中国精算师协会发布的《中国人身保险业经验生命表（2010-2013）》，六张表分别为非养老类业务一表、二表（男、女）与养老类业务表（男、女）。生存函数在基数 1,000,000 与均匀死亡分布（UDD）假设下递推，`Lx`、`Tx`、`ex` 与教材中公布的 CL1 数值逐行一致（`l0/d0/L0/T0/e0 = 1000000 / 867 / 999567 / 76420142 / 76.42`）。除 UDD 外，库内还支持死亡力恒定（CFM）与 Balducci 双曲线两种分数年龄假设。

## 项目结构

```
.
├── cltables.mbt       六张经验表的 qx 数据与业务分类
├── lifetable.mbt      生存函数递推、分数年龄假设、概率函数
├── interest.mbt       利息理论：名义/贴现/力、各类年金
├── valuation.mbt      换算列 D C M N R S 与生命年金
├── insurance.mbt      趸缴/年缴纯保费、准备金、变额保险
├── tables.mbt         ChinaTable 枚举与元数据
├── fmt.mbt            定点小数与对齐排版
├── svg.mbt            零依赖 SVG 渲染器（支持对数轴）
├── *_test.mbt         黑盒与白盒测试
├── examples/
│   └── quickstart/    最小可运行样例
├── cli/               命令行前端：参数解析与六个子命令
│   ├── args.mbt
│   ├── commands.mbt
│   └── run.mbt
└── cmd/main/          可执行文件入口（把 argv 交给 cli，仅此而已）
```

## 测试

```bash
moon test                 # 62 项测试
moon coverage analyze     # 覆盖率报告
```

测试分三层：教科书公布值的逐行校核、与定义式求和的交叉验证（公式与其实现必须错成完全一样才能蒙混过关）、以及边界与退化输入（零利率、空期间、超范围年龄、单点与常量序列）。
